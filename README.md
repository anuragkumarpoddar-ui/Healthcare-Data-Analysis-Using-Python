## Project Overview

This project explores healthcare data using Python to identify meaningful patterns in patient demographics, medical conditions, hospital stays, and billing amounts.

Using **Pandas, NumPy, Matplotlib, and Seaborn**, the project covers data cleaning, exploratory data analysis (EDA), statistical summaries, and data visualization to transform raw healthcare data into useful insights.

## Project Objectives

* Understand the structure and quality of healthcare data.
* Identify and handle duplicate records and invalid values.
* Analyse patient age, medical conditions, and hospital stay duration.
* Explore billing patterns across healthcare records.
* Examine correlations between numerical variables.
* Visualize findings through clear and informative charts.

## Project Workflow

1. **Data Loading:** Import the healthcare dataset into a Pandas DataFrame.
2. **Data Inspection:** Check rows, columns, data types, missing values, and duplicates.
3. **Data Cleaning:** Handle duplicate records, convert date columns, and review invalid billing values.
4. **Feature Engineering:** Calculate length of hospital stay and create age groups.
5. **Exploratory Data Analysis:** Analyse patient demographics, medical conditions, billing, and hospital stays.
6. **Statistical Analysis:** Generate summary statistics and condition-wise comparisons.
7. **Correlation Analysis:** Examine relationships between selected numerical variables.
8. **Data Visualization:** Create charts and a correlation heatmap to communicate findings.

## Key Analysis Areas

* **Patient Analytics:** Age distribution and patient demographics.
* **Medical Conditions:** Patient counts and condition-wise comparisons.
* **Hospital Stay:** Length-of-stay analysis.
* **Billing Analysis:** Average billing amount across medical conditions.
* **Correlation Analysis:** Relationships between numerical variables.
* **Data Quality:** Duplicate records, invalid values, and date consistency.

## How to Run This Project

1. Clone or download this repository.

2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

3. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Open the project notebook and update the dataset path to match your computer.

5. Run the notebook cells in sequence.
